# Loki — Life OS

Aplicação de gerenciamento pessoal com metáfora de prédio de andares (pixel art / 8-bit).

## Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Python FastAPI + SQLite
- IA: Cliente HTTP para inference-api.nousresearch.com/v1 (Hermes/Nous)
- Visual: Pixel-art via CSS + SVG inline
